// Personal Project

DeutschChat

AI-Powered German Language Learning Platform

DeutschChat is a full-stack AI language-learning platform I designed and developed to make learning German more practical and conversational. Instead of relying solely on traditional exercises, the platform allows learners to practise German through realistic conversations with an AI learning companion, Lena.

View Live Site View Code

// Overview

Project Overview

I developed the application across both the frontend and backend, building the responsive user experience, authentication, learning infrastructure, database architecture, and AI-powered chat experience.

The platform uses Next.js, React and TypeScript on the frontend, with Supabase and PostgreSQL powering authentication, learner data, curriculum and persistent conversations. The chat experience is powered by OpenAI's GPT-5.6 Luna through the Responses API, allowing users to have contextual German conversations and interact with individual words for English translations. The application is deployed through Vercel and uses Row Level Security to protect user-specific learning and conversation data.

  • AI Conversation PartnerRealistic German conversations with Lena, powered by GPT-5.6 Luna.
  • Clickable TranslationsTap any German word in a conversation for an instant English translation.
  • Secure & PersistentSupabase authentication and Row Level Security protect learner data and saved conversations.
